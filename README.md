🛒 Smart Grocery Assistant

📌 About the Project

Smart Grocery Assistant is a beginner-friendly Python project that helps users select recipes, calculate ingredient quantities based on the number of people, identify missing ingredients, and estimate grocery shopping costs.

✨ Features

- Recipe selection
- Ingredient quantity calculation
- Missing ingredient detection
- Estimated grocery bill calculation

🛠️ Technology Used

- Python

▶️ How to Run

1. Download "main.py".
2. Install Python on your computer.
3. Open a terminal in the project folder.
4. Run: "python main.py"

🎯 Objective

To make grocery planning easier by helping users identify ingredients and estimate shopping expenses.
